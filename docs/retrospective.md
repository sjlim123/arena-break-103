## 1. AI 협업 중 가장 크게 실패한 사례

무슨 일이 있었고, 왜 그렇게 됐는지 씁니다.

**상황**:사격시스템 과정중

**내가 준 프롬프트**:세번째 사격시스템 만들차례에요
사격 연습용 표적을 Arena 씬에 배치해줘.

- Targets 라는 빈 오브젝트를 Position (0, 0, 0) 에 만들고 그 아래에 자식으로 넣을 것
- Target_1 / Target_2 / Target_3 — 전부 Cube
- Scale (1, 2, 1)
- Position: y=1, z=8, x는 각각 -3 / 0 / 3
- Assets/Materials 에 빨간색 URP Lit 머티리얼을 만들어 표적 3개에 적용할 것



**AI가 내놓은 결과**:씬 작업 전에 에디터가 플레이 모드가 아닌지 먼저 확인할게요. 플레이 중에 만든 오브젝트는 정지하면 사라져요.

플레이 모드가 아니고, 씬에 Targets는 아직 없어요. 먼저 Targets를 만들게요.

큐브 3개와 빨간 머티리얼을 만들게요.

머티리얼을 만들었어요. 색이 실제로 _BaseColor에 들어갔는지 확인한 뒤 표적 3개에 적용할게요.

_BaseColor가 빨강 (1, 0, 0, 1)으로 들어갔어요. 이제 표적 3개에 적용할게요.

이제 요청하신 항목을 씬에서 다시 읽어서 확인할게요.

Target_2와 Target_3을 읽는 중에 Unity 연결 세션이 끊겼다는 오류가 났어요. 재시도하기 전에 상태를 먼저 확인할게요.

도메인 리로드로 연결이 잠깐 끊겼다가 Arena-Break로 다시 붙었고, 고정된 인스턴스가 UNIV_GAMEDEV로 가지 않고 그대로 응답했어요. 씬이 그대로인지 확인하려고 다시 읽을게요.

세 표적 모두 Targets 아래에 위치와 스케일이 맞게 남아 있어요. 이름 검색이 0건이었던 건 정확 일치 방식 탓이니, 실패했던 두 표적의 머티리얼 적용부터 다시 읽어볼게요.

표적 3개 배치를 끝냈고, 요청하신 항목을 모두 다시 읽어서 확인했어요.

**무엇이 잘못됐나**:2. 씬 오브젝트는 먼저 물어볼 것	✅ 두 번 모두 직접 요청하셔서 진행했어요. 요청 없이 만든 오브젝트는 없어요
3. 코드 작성 후 컴파일 확인 ⚠️ 첫 확인은 부정확했어요

**진짜 원인** (프롬프트 문제인가, 내 이해 부족인가, AI의 한계인가):AI가 좀더 명확히 숙지하기 위한 나의 프롬프트가 문제였고 또한 이를 늦게 인지한 나의 이해 부족도 있었다.

**다시 한다면 어떻게 할 것인가**:

규칙을 작성할때 명확히 작성하고 클로드에게 명령을 내리기 전 규직 숙지를 여러번 직접 시키는것이 확실하다.

## 2. AI를 믿었다가 틀린 적이 있는가

AI가 "정상 동작합니다"라고 했지만 실제로는 아니었던 경험,
또는 AI의 코드 리뷰 지적이 틀렸던 경험을 씁니다.
대부분의 작업은 정확했고 다만 작업을 모두 수행하려는 경향이 있어 위 내용처럼 규칙을 몇번 위반함.

**그때 어떻게 알아챘나**: 직접 규칙 관련해서 재질문 및 검증단계를 밟음.

**앞으로 무엇을 검증 기준으로 삼을 것인가**: 작업을 진행하면 세부적인 부분을 직접 묻고 수정 및 앞으로의 숙지사항을 AI 에이전트의 메모리로 추가할것.

## 3. 가장 효과가 좋았던 프롬프트 습관

이 수업에서 발견한 것 중 하나만 고릅니다.

**습관**: 질문이 적었음.

**근거가 되는 사례**: 프롬프트를 복사 붙여넣기 < 이부분을 수업하며 작업할때 내가 모름에도 불구하고 지나친 부분이 빈번했음. 반성하며 고쳐야함.

---

## 4. AI가 대신할 수 없다고 느낀 부분

작업하면서 "이건 결국 사람이 해야 하는구나"라고 느낀 지점을 씁니다.

눈으로만 확인되는 시각적인 부분은 확실히 사람이 해야한다는것을 모든 작업 부분 절차 밟을때마다 느낌.
---

## 5. 다음에 게임을 만든다면

이번 경험을 바탕으로, 처음부터 무엇을 다르게 할 것인가.

에이전트의 부족한부분을 여러가지 스킬과 플러그인을 사용하거나 내가 직접 에이전트 메모리에 지정 및 숙지사항 추가, 세션을 부모세션 및 자식세션 으로 나누어 AI를 여러명의 직원처럼 나누어 쪼개서 작업할것 (이러면 작은 문제를 따로 빠르고 쉽게 해결 가능해짐)
